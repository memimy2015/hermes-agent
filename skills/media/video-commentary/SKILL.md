# Skill 标题
这是一个用于对体育比赛视频配解说的技能。

## 何时使用
当用户指定视频文件，需要对视频配上解说时。

# 具体使用方法
1. 首先要对视频整体内容进行理解，了解比赛背景，参赛双方。同时提取视频切分时间戳，一般需要将正式比赛和其他环节区分开，只有对正式比赛内容才会有配解说，对于正式比赛最好按照进攻回合进行比较细致的切分，对于正式比赛内容，最好切分成每段2分钟以内，但是不要破坏每段内容的相对完整独立。上述内容都要在提示词内体现。提示词示例：
```
请详细描述这个视频中的内容，包括这是什么比赛，参赛双方是哪两支球队/哪些选手。同时提取视频切分时间戳，切分原则如下：
1. 根据内容将视频切分为多个片段，区分正式比赛和其他内容。其他内容包括广告、暂停、新闻、介绍等等所有非比赛内容。
2. 整体返回格式为json，其中一个对象是视频背景介绍，另一个对象为视频切分信息数组，视频切分信息包括片段开始时间、结束时间、片段类型（正式比赛、其他内容）、片段概述（比如是比赛刚开始，还是暂停回来，广告回来，一节比赛末尾等等）。
3. 时间戳格式为：HH:mm:ss
```
2. 提取了比赛背景信息后，对比赛内容做一些前期准备，在互联网上搜索一些双方运动员完整阵容（运动员号码-运动员名字），核心球员，球员特点，双方球队历史战绩等等，以便于润色比赛中的解说内容。注意，必须获取到两个球队完整阵容的号码和运动员姓名，如果没有获取到，则再次搜索。这是一场2026年4月10日的比赛，搜索的时候注意时效。
3. 对视频做切分。仅把比赛片段切分出来，进行后续处理。
4. 对切分后的正式比赛片段，再次调用视频理解，生成解说词，在提示词中要融入在互联网上查询到的背景信息，让整个解说在恰当的时机补充一些外部信息，生成更加自然生动。解说词要根据视频内容一句一句生成，最后组装成json数组，每个json对象包含解说词开始时间，结束时间，解说词内容，解说词情绪。情绪取值范围：["happy", "sad", "angry", "fearful", "disgusted", "surprised", "calm", "fluent", "whisper"]。上述要求要在提示词中体现。
5. 生成解说词时，只有第一个视频片段需要有开场白。后续片段只需解说比赛内容，不需要开场白。最后一个片段需要有对这一节比赛的总结。上述内容要在解说词生成的提示词中体现。
6. 生成解说词时，提示词中要把整个阵容号码，球员名称包含进去，让模型根据提供的号码识别对应的运动员，不需要读阵容名单，运动员在球场上有表现的时候，根据号码能够正确转换成人名即可。生成解说词提示词如下：
```如果是比赛开始片段
# 任务
为比赛片段生成一段解说词
# 背景
{背景信息}
{双方球员号码-姓名列表}
# 要求
1. 解说词要根据视频内容一句一句生成，最后组装成json数组，每个json对象包含解说词开始时间，结束时间，解说词内容，解说词情绪。情绪取值范围：["happy", "sad", "angry", "fearful", "disgusted", "surprised", "calm", "fluent", "whisper"]。
2. 这是比赛开始的第一段片段，解说词要包含比赛开场白，开场白要介绍一些比赛背景，双方的核心球员等内容。
3. 解说词过程中需要根据号码识别球员姓名，不能直接使用号码，球员号码和姓名对应关系参考背景信息。
4. 一定要反复确认每句解说词的开始和结束时间，解说时间要在相应的视频内容发生之后，不能解说剧透。
5. 时间戳格式为：HH:mm:ss
6. 解说词拆分细一些，每句解说词简短，避免过长的句子，解说词和解说时间长度要匹配，避免时间内解说词读不完
7. 解说词要尽可能覆盖比赛更多细节，包括每个回合具体的战术，运动员的配合，不要只解说进球部分，进攻成功和失败都要解说。每个回合都要有单独一句解说词，不要把两个回合合并到一起。
```

```如果是比赛最后一个片段
2. 这是本节比赛的最后一个片段，解说词最后要对本节比赛有一定的总结。

```
5. 对生成的解说词再次调用视频理解，进行二次校对，提示词示例如下：
```
# 针对于视频的解说词进行二次校对。
# 背景
{背景信息}
{双方球员号码-姓名列表}
# 解说词
{解说词}
# 校对规则
1. 校对解说词是否符合视频内容，是否包含错误的信息。
2. 解说词中的球员名字，是否与背景信息中的球员号码-姓名列表匹配。
3. 重点！重点！解说词的时间戳与视频时间是否匹配，如果不匹配则进行响应调整，确保解说词发生在视频内容出现之后的恰当时机。一定要反复确认每句解说词的开始和结束时间，解说时间要在相应的视频内容发生之后，不能解说剧透。
4. 解说词的时间戳不能出现重叠的部分。
4. 校对后输出完整的解说词，格式遵循原格式。
```
6. 解说词也持久化到当前目录的commentary目录下，文件名格式为commentary_000.json，000为片段序号。
7. 解说词合成音频
8. 对视频片段去除人声，再合并上合成好的解说音频
9. 将处理后的比赛片段合并到一起
10. 获取到最终生成的视频后，清除ark服务器上的文件

# 可以使用的脚本
- scripts/video_content_understanding.py
    - 用于对视频进行内容理解，提取视频中的关键信息。
    - 入参
        - input: 视频文件路径。
        - prompt: 提示词，用于对视频内容进行提问。
    - 出参
        - 内容理解结果
    - 调用示例
        - python scripts/video_content_understanding.py --video video.mp4 --prompt "描述视频内容，主要包含：这是一场什么比赛，参赛双方都有谁"
- scripts/cut_segments.py
    - 用于将视频切分成多个片段。
    - 入参
        - video: 视频文件路径。
        - segments: 视频片段信息描述，格式为JSON文件。格式如下：
        ```json
        [
            {
                "start_time": "00:00:00",
                "end_time": "00:10:10",
                "name": "000_game"
            }
        ]
        ```
    - 出参
        - 切分后的视频片段文件路径列表
    - 调用示例
        - python scripts/cut_segments.py --video video.mp4 --segments segments.json
- scripts/remove_voice.py
	- 清除原视频中的人声。
	- 入参
		- video: 视频文件路径
	- 出参
		- 处理后的视频文件路径
- scripts/tts.py
	- 解说词合成音频
	- 入参
		- text: 需要合成音频的文本信息
		- emotion: 音频情绪（可选值包括：["happy", "sad", "angry", "fearful", "disgusted", "surprised", "calm", "fluent", "whisper"]）
		- name: 音频文件名称（mp3格式）
	- 出参
		- 合成的mp3格式音频文件
	- 示例
		- python scripts/tts.py --text '欢迎来到比赛现场' --emotion 'calm' --name '001_001.mp3'
- scripts/merge_voice.py
	- 音频融合到视频中。
	- 入参
		- video: 视频文件
		- audios: 音频文件描述，json文件，格式示例如下：
		```json
		[
			{"start_time": "00:00:00", "end_time": "00:00:07", "audio": "tts/001.mp3"}
		]
		```
	- 出参
		- 输出文件
	- 示例
		- python scripts/merge_voice.py --video 001.mp4 --audios audio.json
- scripts/merge_video.py
	- 将处理好的视频片段合并。
	- 入参
		- videos: 视频片段列表
		- output: 输出文件名称
	- 出参
		- 输出视频文件路径
	- 示例
		- python scripts/merge_video.py --videos '["merged_segments/001.mp4","merged_segments/002.mp4"]' --output pro.mp4
- scripts/ark_file_clear.py
	- 清空ark服务器上的文件
	- 入参
		- 无
	- 出参
		- 无
	- 示例
		- python scripts/ark_file_clear.py

# 说明
- 只能使用上述脚本，不要尝试自己写代码，如果连续执行失败，则直接退出流程，并告知失败原因
- 调用视频理解时候的提示词，要尽可能描述详细清晰
- 不要试图通过代码直接串联流程，每一步都要观察上一步执行的结果再进行处理
- 大体流程按照使用方法中的步骤，在中间可以根据情况动态调整，比如基于前面的视频片段理解输出，可以再次进行相关内容的搜索，然后调整后续视频的理解和解说词生成
- 上述过程不要进行询问，直接完整执行，遇到写文件等问题，调整方法重试
- 在调用完脚本，需要把json内容写入本地文件时，注意要转换为字符串文本，不要以list或者dict对象的方式写入文件，否则会导致写文件失败
- 注意，解说词以及解说音频所对应的时间戳，均是当前视频片段的时间戳，不需要计算成完整视频的时间戳，因为音频合成等处理也都是在片段上完成，最后才进行片段合并
- 一定要注意校对解说词！重要！重要！
